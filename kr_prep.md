# Подготовка к контрольной работе

## Когда merge и когда rebase
Merge выбираю для общей ветки и сохранения истории интеграции. Rebase использую для своей ветки до передачи изменений коллегам.

## Rebase общей ветки
Изменятся SHA коммитов, и ветки коллег разойдутся с обновлённой историей. Потребуется согласованное восстановление их работы.

## Multi-remote
Несколько remote полезны для форка с upstream, резервной копии и миграции между хостингами.
