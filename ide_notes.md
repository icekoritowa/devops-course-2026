# Git в VS Code и терминале

1. Source Control показывает изменённые файлы и позволяет выбирать изменения для индекса.
2. Diff сопоставляет старую и новую версии и выделяет добавления и удаления.
3. История и blame помогают найти автора строки и связанный коммит; GitLens расширяет эти возможности.

В терминале удобнее интерактивный rebase: явно видны диапазон коммитов и план pick/reword/fixup/drop.
