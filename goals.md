# Цели на семестр

1. Создать Dockerfile для Python-приложения, собрать образ
   и проверить запуск контейнера одной командой docker run.
2. Настроить GitHub Actions для автоматического запуска тестов
   при каждом push и pull request; получить успешный запуск CI.
3. Развернуть приложение на Linux, настроить запуск через systemd
   и проверить SSH-доступ и HTTP-ответ сервиса.
